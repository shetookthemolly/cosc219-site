# Why is #trails private rather than public?
Because in Object Oriented Programming, one of the fundamental principles is encapsulation, which is the practice of restricting direct access to internal data, and instead providing safer and more controlled ways to access the data. We are applying this principle by making #trails private and giving it getters and setter methods to safely access it. We apply this principle to have a proper object-oriented design.
